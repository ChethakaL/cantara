PART I — BOARD OVERVIEW & OPERATING INTENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


1. Purpose of the Board
The Cantara Monday Sales Lead Board will manage qualified pet resort prospects through a disciplined four-touch
cold outbound sequence from initial Email 1 through either a booked meeting, a nurture handoff, or another
defined exception status.
  PRIMARY DESIGN PRINCIPLE​
  This board is a workflow-management tool. It is not a full prospect database and it is not the post-booking sales
  pipeline.



2. What the Board Must Achieve
●​ Give Craig, Gabriela, and Stephanie an immediate daily view of which prospects require action.
●​ Make the next required step unmistakable for every active lead.
●​ Preserve the same-caller-both-attempts rule for Call 1 and Call 2.
●​ Automate the 21-calendar-day sequence wherever practical.
●​ Capture only the structured data required for workflow, automation, filtering, reporting, or recurring
   management decisions.
●​ Move booked opportunities out of this board and into the Deals/CRM workflow.
●​ Move defined nurture dispositions into the Nurture board.

5. Board Users
Initial outbound callers:
●​ Craig
●​ Gabriela
●​ Stephanie
The Assigned Caller is not a general lead-owner field. It identifies the person responsible for both Call 1 and Call 2.
The same assigned caller should make both attempts unless Cantara manually reassigns the lead.

6. What Success Looks Like
 DAILY-USE STANDARD​
 A caller should be able to open Active Triage and, within seconds, understand which leads require action, what
 action is required, and when it is due.


An active lead should not remain in the sequence without a clearly defined Current Stage and Next Action Date.
The board should minimize manual maintenance, but it must preserve transparent status and date logic so Cantara
can audit the process.

G. Automation Build Recipes
A1 — Start Email 1
Trigger: Current Stage changes to Email 1 Due.
Actions: Send Email 1 through the approved Gmail/email integration; set Current Stage to Email 1 Sent; set Last
Contact Date to today; set Next Action Date to today + 7 calendar days.
Expected Result: Lead waits in Email 1 Sent until the Call 1 due-date automation fires.

A2 — Make Call 1 Due
Trigger: Next Action Date arrives AND Current Stage = Email 1 Sent.
Actions: Set Current Stage to Call 1 Due.
Expected Result: Lead appears as due in Active Triage.

A3 — Complete Call 1
Trigger: Last Call Result changes while Current Stage = Call 1 Due.
Actions: Set Last Contact Date to today; unless Current Stage is manually changed to an approved exception, set
Current Stage to Email 2 Due; set Next Action Date to today + 7 calendar days.
Expected Result: Standard sequence advances to Email 2 Due; exception paths pause or stop normal automation.

A4 — Send Email 2
Trigger: Current Stage changes to Email 2 Due.
Actions: Send Email 2 through the approved Gmail/email integration; set Current Stage to Email 2 Sent; set Last
Contact Date to today; set Next Action Date to today + 7 calendar days.
Expected Result: Lead waits in Email 2 Sent until the Call 2 due-date automation fires.

A5 — Make Call 2 Due
Trigger: Next Action Date arrives AND Current Stage = Email 2 Sent.
Actions: Set Current Stage to Call 2 Due.
Expected Result: Lead appears as due in Active Triage.

A6 — Complete Call 2
Trigger: Last Call Result changes while Current Stage = Call 2 Due.
Actions: Set Last Contact Date to today. Caller applies the correct terminal or exception Current Stage. If no
response and no exception applies, set Current Stage to Completed – No Response.
Expected Result: No lead remains indefinitely in Call 2 Due after a completed call.

A7 — Callback Exception
Trigger: Current Stage changes to Needs Follow-Up.
Actions: Pause normal sequence automation. Next Action Date is manually set to the agreed callback date.
Expected Result: Lead is retained for a specific follow-up and does not auto-advance through the standard
cadence.

A8 — Reconnect Later Exception
Trigger: Current Stage changes to Reconnect Later.
Actions: Pause normal sequence automation.
Expected Result: Lead does not continue through the standard four-touch sequence.

A9 — Nurture Handoff: No Response
Trigger: Current Stage changes to Completed – No Response.

A10 — Nurture Handoff: Not Interested

Interested – To Nurture, or Booked.
Actions: Prevent any future standard sequence stage/date automations from advancing the lead.
Expected Result: Terminal or handed-off leads do not re-enter the sequence.

K. Prospect Admission Criteria
A lead should enter the Active Sequence Board only after passing Cantara's current ICP qualification:
●​   Independent operator; not a multi-state chain or franchise.
●​   Offers dog boarding and/or daycare.
●​   Exclude grooming-only and vet-clinic operations.
●​   Minimum Google rating of 4.5.
●​   At least 50 Google reviews.
Qualification and enrichment occur before import. The Active Sequence Board is not the place to decide whether a
lead meets the ICP.
